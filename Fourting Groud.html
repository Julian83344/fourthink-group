Cara order

Empat langkah dari pilih paket sampai Robux masuk.

  1. Pilih paket

    Tentukan jumlah Robux dan isi username Roblox Anda pada formulir pesanan.

  2. Kirim ke admin

    Tekan tombol WhatsApp. Pesan berisi paket dan username sudah terisi, tinggal dikirim.

  3. Konfirmasi dan bayar

    Admin membalas dengan harga final, metode pengiriman, dan cara pembayaran.

  4. Robux diproses

    Setelah pembayaran diterima, admin memproses pesanan dan mengabari Anda.
